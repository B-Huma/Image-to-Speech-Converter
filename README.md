# 🖼️📝🎤 Image to Speech Converter

Bu uygulama, yüklenen bir görseldeki metni algılar ve
seçilen okuma tarzına göre doğal bir sesle okur.

## 🚀 Özellikler
- Görselden metin çıkarma (OCR)
- Tonlamalı Text-to-Speech
- Streamlit arayüz

## ▶️ Çalıştırma
```bash
pip install -r requirements.txt
streamlit run app.py
